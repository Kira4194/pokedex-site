Comment lire la vitrine. Passez la souris ou le doigt sur une carte pour la faire briller, touchez-la pour l'agrandir. Le prix affiché est la moyenne des ventes Cardmarket sur 7 jours, en euros. Le prix est relevé chaque matin dans le guide des prix officiel de Cardmarket ; la page le lit toute seule à l'ouverture.
